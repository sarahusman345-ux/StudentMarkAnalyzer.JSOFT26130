# Student Marks Analyzer

## Project Description
A simple C++ mini project that analyzes student marks.

## Features
- Read student marks
- Calculate total marks
- Calculate average marks
- Find highest mark
- Find lowest mark
- Count passed and failed students
- Display analysis report
- Repeat analysis

## Concepts Used
- Arrays
- Functions
- Loops
- Conditional statements
- Input and output

## Language
C++
